# Student Result Management System (SRMS)

## Problem Statement
Managing student details, marks, and result reports manually is time-consuming, error-prone, and difficult to scale as the number of students increases. Teachers often rely on spreadsheets or handwritten records, which can lead to data inconsistency, miscalculations, and difficulty in retrieving information.  
There is a need for a simple, efficient software tool that automates these tasks, ensures accuracy, and provides quick access to student performance data.

## Scope of the Project
The Student Result Management System (SRMS) is a console-based Java application that allows users to manage students, subjects, and marks. The system calculates total marks, percentage, grades, and pass/fail status automatically. The project focuses on basic CRUD operations, result generation, and structured data handling using Java OOP concepts and Collections.

### In Scope
- Add, update, delete, and list students  
- Add and manage subjects  
- Enter and update marks  
- Generate individual student result reports  
- Generate class-wise summary reports  
- Validation of inputs (ID, marks range, etc.)

### Out of Scope
- GUI or web interface  
- Multi-user login or authentication  
- External databases (only in-memory data structures used)

## Target Users
- Teachers or faculty members handling student records  
- Coaching centers and small institutes  
- Students learning Java who need a basic but structured project  
- Anyone who needs a lightweight result calculation tool

## High-Level Features
- Student Management Module  
- Subject Management Module  
- Marks Entry & Update Module  
- Automatic Result Calculation  
- Individual Student Report  
- Class Summary Report  
- Input Validation & Error Handling
