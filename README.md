# Student Result Management System (SRMS)

A simple, menu-driven Java console application for managing student information, subjects, and marks.  
The system automatically calculates total marks, percentage, grade, and pass/fail status for each student.

---

## 📌 Overview
The Student Result Management System (SRMS) is designed to simplify the process of storing student details, managing marks, and generating results.  
It demonstrates Java concepts such as:
- Object-Oriented Programming (OOP)
- Collections Framework (ArrayList)
- Modular structure with packages
- Input validation and error handling

This is a lightweight academic project suitable for Java beginners or course evaluations.

---

## ✨ Features
### ✔ Student Management
- Add student  
- Update student  
- Delete student  
- View all students  

### ✔ Subject Management
- Add subject  
- List subjects  

### ✔ Marks Management
- Enter marks for each subject  
- Update marks  
- Validate marks (0–100 or subject max marks)

### ✔ Result Generation
- Calculate total, percentage, grade  
- Determine pass/fail  
- View detailed student report  
- View overall class result summary
